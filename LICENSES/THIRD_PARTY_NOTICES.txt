  * libdeflate (MIT)
  * FreeType (FTL or GPL-2)

For the canonical license texts of these libraries refer to the Qt

None of these libraries impose copyleft obligations on UFB.

===============================================================================

UFB's Rust crates (core/, bindings/, agent/) pull in a substantial
graph of dependencies via Cargo. The vast majority are dual-licensed
MIT OR Apache-2.0; a minority are BSD-2 / BSD-3 / ISC / Unlicense /
CC0. None impose copyleft obligations.

The complete, generated attribution for every crate compiled into
UFB's binaries — package, version, license, and the full license text
with each crate's copyright notice — ships alongside this file as:

    RustCrates-NOTICES.txt        (regenerate: scripts/gen-rust-notices.sh)

It is produced by cargo-about from Cargo.lock (about.toml at the repo
